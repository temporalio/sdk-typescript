`@temporalio/google-adk-agents` now requires `@google/adk` `>=2.0.0 <2.1.0` (was `>=1.5.0 <1.6.0`); ADK 2.0 changed its internals and ID generation, so Workflows started with the 1.5 plugin cannot be replayed by this version: drain in-flight Workflows before upgrading or run the versions on separate task queues. `@modelcontextprotocol/sdk` is now an optional peer dependency, needed only for `TemporalMCPToolset`.
