Experimental `TemporalOperationHandler` callbacks drop their context argument. Use `start(client, input)` or `cancelWorkflowRun(options)`, `cancelWorkflowUpdate(options)`, and `cancelActivity(options)`. Read service, operation, start request ID, and invocation cancellation via `operationInfo()`, and read request headers in a Worker Nexus interceptor. The live `cancellationSignal` is available by direct access but is omitted from serialized operation info.
